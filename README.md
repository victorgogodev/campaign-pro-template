# Campaign Pro Template

Kenya 2027 election campaign website template built with React, Tailwind CSS, and Node.js.

## Stack
- React + Vite
- Tailwind CSS
- Node.js + Express
- M-Pesa Daraja API

## Services
- Campaign Pro — candidate websites
- Results Live — election night dashboards
- Campaign Ops — internal campaign management tools
